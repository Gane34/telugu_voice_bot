# Open Source Audit

| Component | Project | License | Local? | Paid API required? |
|---|---|---|---|---|
| Pipecat | pipecat-ai | Open-source project | Yes | No |
| IndicConformer | AI4Bharat IndicConformer | Open-weight / research license depending on model | Yes | No |
| IndicF5 | AI4Bharat IndicF5 | Open-weight / research license depending on model | Yes | No |
| Whisper/faster-whisper | OpenAI Whisper / faster-whisper | MIT / open-weight | Yes | No |
| Ollama | Ollama | Open-source runtime | Yes | No |
| Qwen model | Qwen Instruct | Open-weight model license | Yes | No |
| FastAPI | FastAPI | MIT | Yes | No |
| SQLite | SQLite | Public domain | Yes | No |
| PostgreSQL | PostgreSQL | PostgreSQL License | Yes | No |
| Twilio/Telnyx | Twilio/Telnyx | Proprietary telecom service | No | Yes (carrier service) |

Important note: open-weight models are not necessarily OSI-approved open-source. They may be open-weight/local models with licensing restrictions. The system should treat those as local models, not as guaranteed public-domain software.
